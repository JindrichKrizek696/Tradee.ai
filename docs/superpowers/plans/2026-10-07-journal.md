# Deník obchodů + průvodce připojením MetaTraderu – implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Záložka Deník (seznam obchodů, detail se svíčkovým grafem, tagy/poznámka/screenshoty, statistiky) nad MT i ručními obchody, EA 1.1 posílající svíčky k uzavřeným obchodům a průvodce připojením MetaTraderu pro začátečníky na `/mt`.

**Architecture:** Čisté moduly `lib/journal/{types,rows,stats,format,chart-data}.ts` a `lib/mt/bars.ts` (testované v Node skriptem `scripts/check-journal.mjs` / `check-mt.mjs`), DB vrstva `lib/journal/store.ts` + `lib/rates-db.ts` (bere `Db` jako parametr), route handlery `app/api/journal/*`, UI v `app/journal/*` (klientské komponenty, statistiky se počítají v prohlížeči). Svíčky: server v `/api/mt/state` řekne EA, ke kterým uzavřeným obchodům je chce (`barsWanted`), EA je pošle událostí `bars` mimo svou frontu.

**Tech Stack:** vinext (Next 16 App Router, Workers runtime), MariaDB přes `lib/mysql.ts` (`dateStrings`, `decimalNumbers`), R2 binding `BUCKET`, `lightweight-charts` v5 (Apache 2.0), lucide-react, MQL5/MQL4.

**Spec:** `docs/superpowers/specs/2026-10-07-journal-design.md` (navazuje na `docs/superpowers/specs/2026-10-07-mt-sync-design.md`)

## Global Constraints

- Svíčky: nejvýš **1000** v události, EA volí okno s **≤ 600** svíčkami; řada TF **M1, M5, M15, M30, H1, H4, D1**; okno = `open − max(20 % délky, 30 min)` až `close + max(20 % délky, 30 min)`.
- Svíčky se chtějí jen k pozicím uzavřeným **≥ 5 min** a **≤ 30 dní** zpět; nejvýš **20** položek `barsWanted` v odpovědi; EA posílá nejvýš **10** událostí `bars` v jednom POST.
- EA verze **1.1.0** (MT5 i MT4), stránka `/mt` hlásí starší verzi.
- Tagy: max **10** na obchod, každý **2–30** znaků `[0-9a-zÀ-ɏ_-]`, ukládají se malými písmeny bez `#`.
- Poznámka MT obchodu max **5000** znaků, ručního **500** znaků.
- Screenshoty: **PNG, JPEG, WebP**, max **5 MB**, max **5** na obchod, R2 klíč `journal/<user>/<uuid>`.
- Tabulka obchodů: stránkování po **50**.
- Pásma držení: **< 15 min, 15 min–1 h, 1–4 h, 4–24 h, 1–7 d, > 7 d**.
- Časy v UI a rozpady podle hodiny/dne: **Europe/Prague**; datum MT obchodu = den uzavření v Europe/Prague.
- Ruční obchody: v deníku jen datum, trh, výsledek, poznámka; do R, MFE/MAE, držení a hodiny vstupu se nepočítají; nepřepočítávají se (hodnota = měna souhrnu).
- Kód drží styl repa (kompaktní TS, české komentáře a hlášky). Čisté moduly v `lib/` importují jen `import type` nebo relativně s příponou `.ts` (kvůli `node --experimental-strip-types`); UI a routy používají `@/…`.
- Testy: `node --experimental-strip-types scripts/check-mt.mjs` a `node --experimental-strip-types scripts/check-journal.mjs` (vše `ok`), typy `npx tsc --noEmit -p .` (bez výstupu).
- Na VPS se nikdy necommituje. Merge, push a nasazení jen po výslovném souhlasu Daniela.
- Commity končí trailerem `Co-Authored-By:` s modelem, který commit napsal.

## Odchylky / upřesnění oproti specu

- **`barsWanted` místo `barsKnown`:** `/api/mt/state` vrací seznam řetězců `pozice|symbol|tf|od|do` (od/do v s UTC), které má EA poslat. Server tak sám řeší okno, timeframe, 5min odklad a 30denní limit; EA je pro MT5 i MT4 stejně jednoduché. EA se ptá při připojení a pak každých **5 min**.
- **10 místo 20** událostí `bars` v jednom POST (20 × 600 svíček by se blížilo limitu 1 MB). Odpověď `barsWanted` má max 20 položek.
- **Prázdné pole `bars` je platné** (broker historii nemá) – uloží se, aby se server přestal ptát; detail pak ukáže hlášku „Graf není k dispozici“.
- Validace svíček nevyžaduje kladné ceny (záporné ceny existují); vyžaduje `h ≥ max(o,c)` a `l ≤ min(o,c)`.
- `prev`/`next` v detailu se počítá v prohlížeči z aktuálně filtrovaného seznamu (spec je uváděl v API; filtr zná jen klient).
- `mt_positions.tags_manual` se rozšíří na `VARCHAR(400)` (10 × 30 znaků + čárky se do 255 nevejde).
- Průvodce je jeden soubor `app/mt-guide.tsx` (obsah, volba platformy i seznam obrázků `GUIDE_IMAGES`).
- „Účet žije“ (zelená tečka, krok Ověření) = poslední data **< 20 min** (EA bez otevřených pozic posílá snímek jen každých 15 min – dnešních 5 min dává falešně šedou tečku).
- Načtení měny souhrnu a kurzů se vytáhne z `app/api/trades/route.ts` do `lib/rates-db.ts` (používá ho i deník).
- Ruční obchod jde v deníku otevřít také – detail ukáže výsledek a editovatelnou poznámku (PATCH ručního obchodu ze specu potřebuje UI).

- [ ] **Step 4: Vytvoř `lib/mt/bars.ts`**

```ts
// Okno a timeframe svíček pro graf obchodu. Server je posílá EA v /api/mt/state (barsWanted), EA jen zavolá CopyRates.
import type {Timeframe} from './protocol.ts';
const TF:[Timeframe,number][]=[['M1',60],['M5',300],['M15',900],['M30',1800],['H1',3600],['H4',14400],['D1',86400]];
export const MAX_WINDOW_BARS=600;
// okraj před vstupem i po výstupu = 20 % délky obchodu, aspoň 30 min; nejmenší TF, při kterém je v okně ≤ 600 svíček
export function barsWindow(openMs:number,closeMs:number):{tf:Timeframe;from:number;to:number}{
 const dur=Math.max(0,closeMs-openMs),pad=Math.max(dur*0.2,30*60000),from=openMs-pad,to=closeMs+pad;
 const [tf]=TF.find(([,s])=>(to-from)/(s*1000)<=MAX_WINDOW_BARS)||TF[TF.length-1];
 return {tf,from:Math.floor(from/1000),to:Math.ceil(to/1000)};
}
// řádek pro EA: "pozice|symbol|tf|od|do" (s UTC); symbol se znaky, které by rozbily jednoduchý parser v EA, se vynechá
export function wantedLine(position:string,symbol:string,openMs:number,closeMs:number):string|null{
 if(!/^[^|"\]\\\u0000-\u001f]{1,32}$/.test(symbol))return null;
 const w=barsWindow(openMs,closeMs);
 return [position,symbol,w.tf,w.from,w.to].join('|');
}
```
