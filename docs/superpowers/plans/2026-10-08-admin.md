# Admin stránka – implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stránka `/admin`: přehled provozu, správa lidí (schválit, zablokovat, role), stav MT účtů a pro vlastníka nahlížení do cizího deníku jen pro čtení se záznamem.

**Architecture:** Čistý modul `lib/admin/rules.ts` (kdo smí co, s testy), DB vrstva `lib/admin/store.ts`, pomocníci oprávnění `lib/admin/http.ts`, routy `app/api/admin/*`, rozšíření deníkových rout o `?as=` (jen vlastník, jen čtení, audit). UI `app/admin/*` ve stylu `/mt`; cizí deník = stávající komponenta `Journal` v režimu `viewAs`.

**Tech Stack:** vinext (Next 16 App Router, Workers runtime), MariaDB přes `lib/mysql.ts` (`dateStrings`), lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-08-admin-design.md`

## Global Constraints

- Vlastník = `isOwner(email)` / `User.owner`; admin = `role==='admin'`; vlastník je vždy i admin.
- Každá `/api/admin/*` routa kontroluje oprávnění na serveru; chyba oprávnění = **403** `{error:'Na tohle nemáš oprávnění.'}`.
- Ostatní admini **nikdy** nedostanou zůstatek, equity, měnu účtu, obchody ani audit (pole se do odpovědi vůbec nedávají).
- Měnit role smí jen vlastník; vlastníka nelze blokovat ani měnit jeho roli; nikdo nemůže blokovat ani měnit roli sám sobě.
- Přístup do aplikace: vlastník, nebo `waitlist.approved=1 AND waitlist.blocked=0`. Po změně stavu `forgetAccess(memberId)`.
- `?as=<memberId>` jen u čtení (GET) deníku a jen pro vlastníka; zápisy (PATCH/POST/DELETE) parametr ignorují – vždy jen za sebe.
- Audit akce: `approve`, `block`, `unblock`, `role_admin`, `role_member`, `view_journal`, `view_trade`.
- „Online“ MT účet = `last_seen` < **20 min**; „stará verze EA“ = pod **1.1.0**.
- Styl repa: kompaktní TS/TSX, české texty a komentáře; `lib/` moduly importují relativně s `.ts`.
- Testy: `node --experimental-strip-types scripts/check-admin.mjs`, `scripts/check-journal.mjs`, `scripts/check-mt.mjs` (vše ok), `npx tsc --noEmit -p .`, `npm run build`.
- Na VPS se necommituje; merge, push a nasazení jen po souhlasu Daniela.
- Commity končí trailerem `Co-Authored-By:` s modelem, který commit napsal.

## Review Focus

- **Admin (ne vlastník) zkusí `?as=` nebo `/api/admin/audit`** → 403, žádná data → pin: Task 3 `viewAs` + Task 7 ruční test jako Jindřich/Marko.
- **Admin zablokuje vlastníka nebo sám sebe / povýší se** → 400 s českou hláškou → pin: Task 1 testy `canDo`.
- **Zablokovaný uživatel s platnou session** → do 30 s ztratí přístup (auth/check 401, EA 403) → pin: Task 2 `accessRole` + Task 7 ruční test.
- **Vlastník v cizím deníku omylem upraví tag/poznámku** → UI nenabízí, server zapisuje jen za přihlášeného → pin: Task 6 `readOnly` + zápisové routy beze změny.

```ts
// Kdo smí co v administraci (čisté funkce, testy scripts/check-admin.mjs).
export type Actor={id:string;role:string;owner:boolean};
export const ADMIN_ACTIONS=['approve','block','unblock','role_admin','role_member'] as const;
export type AdminAction=typeof ADMIN_ACTIONS[number];
export const isAdmin=(a:Actor)=>a.owner||a.role==='admin';
export function canDo(actor:Actor,action:AdminAction,target:{isOwner:boolean;memberId:string|null}):string|null{
 if(!isAdmin(actor))return 'Na tohle nemáš oprávnění.';
 if(action==='approve')return null;
 if(target.isOwner)return 'Vlastníka nelze blokovat ani měnit jeho roli.';
 if(target.memberId&&target.memberId===actor.id)return 'Sám sebe zablokovat ani měnit si roli nemůžeš.';
 if(action==='role_admin'||action==='role_member'){if(!actor.owner)return 'Role může měnit jen vlastník.';if(!target.memberId)return 'Uživatel se ještě nepřihlásil.'}
 return null;
}
export function personStatus(p:{approved:number;blocked:number;isOwner:boolean}){return p.isOwner?'owner' as const:Number(p.blocked)?'blocked' as const:Number(p.approved)?'approved' as const:'pending' as const}
// verze EA pod 1.1.0 (svíčky pro graf posílá až 1.1)
export function isOldEa(v:string|null){const m=(v||'').match(/^(\d+)\.(\d+)/);if(!m)return true;const [a,b]=[Number(m[1]),Number(m[2])];return a<1||(a===1&&b<1)}
```
Pozor na pořadí v `canDo`: test „vlastníka nelze…“ s adminem i u role_* očekává hlášku o vlastníkovi (kontrola vlastníka je před kontrolou role).

```ts
// Oprávnění pro /api/admin/* a čtení deníku za jiného uživatele (?as=, jen vlastník).
import {identity,db,type User} from '../server.ts';
import {isAdmin} from './rules.ts';
export const forbidden=()=>Response.json({error:'Na tohle nemáš oprávnění.'},{status:403,headers:{'Cache-Control':'no-store'}});
export async function adminUser(req:Request):Promise<User|Response>{const u=await identity(req);return isAdmin(u)?u:forbidden()}
export async function ownerUser(req:Request):Promise<User|Response>{const u=await identity(req);return u.owner?u:forbidden()}
export async function viewAs(req:Request,u:User):Promise<{userId:string;viewing:boolean}|Response>{
 const as=new URL(req.url).searchParams.get('as');
 if(!as||as===u.id)return {userId:u.id,viewing:false};
 if(!u.owner)return forbidden();
 if(!/^[\w:.-]{1,128}$/.test(as)||!await db().prepare('SELECT id FROM members WHERE id=?').bind(as).first())return Response.json({error:'Uživatel nenalezen.'},{status:404,headers:{'Cache-Control':'no-store'}});
 return {userId:as,viewing:true};
}
```
